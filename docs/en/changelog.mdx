Full release notes, downloads and checksums are on [GitHub Releases](https://github.com/l0ng-ai/openidea/releases). OpenIDEA updates itself: use **Check for Updates**.

<Update label="0.1.40" description="2026-11-09">
  Adds an opt-in built-in MCP server, Ruby debugging, .NET workflows, Docker dashboards in Services, attached projects and a shared Java language server across builds, makes switching editor tabs and long agent conversations faster, and ships Plugin API 1.4.

[Release notes](https://github.com/l0ng-ai/openidea/releases/tag/v0.1.40)

</Update>

<Update label="0.1.39" description="2026-11-08">
  Adds dev containers, an editable database result grid, Tomcat Server run configurations, a Project Structure dialog, JetBrains settings import and a rebuilt agent conversation view, and ships Plugin API 1.3.

[Release notes](https://github.com/l0ng-ai/openidea/releases/tag/v0.1.39)

</Update>

<Update label="0.1.38" description="2026-11-06">
  Adds Docker and Compose run targets, Oracle data sources, Astro support, PHP Remote Debug with PHPStan and PHP-CS-Fixer, Ruby test runs with coverage, a choice of update source with a China mirror, and ships Plugin API 1.2.

[Release notes](https://github.com/l0ng-ai/openidea/releases/tag/v0.1.38)

</Update>

<Update label="0.1.37" description="2026-11-05">
  Opens WSL projects directly, debugs Flutter apps, adds Git Blame in diffs and an Android Logcat tool window, and ships Plugin API 1.1.

[Release notes](https://github.com/l0ng-ai/openidea/releases/tag/v0.1.37)

</Update>

<Update label="0.1.0 – 0.1.36" description="2026-10-22 – 2026-11-04">
  The first public releases. See [GitHub Releases](https://github.com/l0ng-ai/openidea/releases) for each version's
  changes.
</Update>
