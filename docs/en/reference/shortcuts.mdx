---
title: "Keyboard shortcuts"
description: "The most-used default shortcuts of OpenIDEA's IntelliJ IDEA keymaps, for macOS and for Windows and Linux."
---

These are the default shortcuts: the **macOS** keymap on macOS, and the **Windows** keymap on Windows and Linux. Both follow IntelliJ IDEA. If you switched to a VS Code or Eclipse keymap, or changed shortcuts, see **Help › Keymap Reference** in the IDE for the bindings in effect, or **Settings › Keymap** to change them ([Keymaps](/en/guide/keymap)).

macOS symbols: `⌘` Command, `⌥` Option, `⌃` Control, `⇧` Shift, `↵` Return, `⌫` Delete, `⌦` Forward Delete, `⎋` Escape, `⇥` Tab. `⇧⇧` and `Shift Shift` mean pressing Shift twice; `⌃⌃` and `Ctrl Ctrl` mean pressing Control twice. Where two shortcuts are listed, either works.

Some shortcuts depend on where the focus is. For example `⌘N` / `Alt+Insert` is **Generate…** in an editor and **New** in the Project tool window, and `⌘R` / `Ctrl+F5` reruns the selected configuration in the Run and Debug tool windows.
