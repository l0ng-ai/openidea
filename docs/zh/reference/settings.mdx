大多数设置在设置窗口中修改最方便（参见[设置](/zh/guide/settings)）。本页介绍设置窗口背后的文件，方便你手动编辑、共享或用脚本处理。

## 文件与层级

设置由三层合并而成，后一层覆盖前一层：

1. 内置默认值。
2. 全局文件，即配置目录中的 `settings.toml`：
   - macOS：`~/Library/Application Support/ai.l0ng.openidea/settings.toml`
   - Windows：`%APPDATA%\ai.l0ng.openidea\settings.toml`
   - Linux：`~/.config/ai.l0ng.openidea/settings.toml`
3. 项目文件 `<项目>/.openidea/settings.toml`，在设置页选中 **此项目** 并保存时写入。

每个文件只保存与下层不同的值。表（table）按键逐个合并；而单个值或数组会整个替换下层的值（例如在项目中设置 `files.exclude`，会替换全局的整个列表）。

有些设置在项目文件中会被忽略：`mcpServer` 和导入的配色方案（`editor.customSchemes`）只能全局配置。项目信任状态永远不会从设置文件中读取。

## 文件格式

文件为 TOML 格式。键名使用下文列出的 camelCase 名称，并按节（section）分组：

```toml
keymap = "intellij-windows"

[appearance]
theme = "dark"
zoom = 110

[editor]
fontFamily = "JetBrains Mono"
fontSize = 14

[files]
exclude = ["**/.git", "**/node_modules", "**/target", "**/dist"]
```

- OpenIDEA 写入文件时会保留你的注释和格式。
- 如果某个文件无法解析，或者某个值类型不对，整个文件都会被忽略，并在[日志](/zh/reference/data-directories)中记录警告。其他层仍然有效。
- 窗口加载设置时才会读取这些文件。手动编辑后，请重启 OpenIDEA（或重新打开项目）以确保生效。

## 设置页

| 分组             | 页面                                                                                                                                                                                                                                                            |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 外观与行为       | 外观；系统设置（语言和地区、日期格式、HTTP 代理、更新）；通知                                                                                                                                                                                                   |
| 按键映射         | 按键映射                                                                                                                                                                                                                                                        |
| 编辑器           | 常规（自动导入、外观、痕迹导航、代码补全、代码折叠、编辑器标签页、装订区域图标、内联补全、后缀补全、富文本复制、智能键、粘滞行）；代码编辑；字体；配色方案；代码样式；检查；自然语言（拼写）；文件和代码模板；文件编码；实时模板；文件类型；嵌入提示；TODO；Vim |
| 插件             | 插件                                                                                                                                                                                                                                                            |
| 版本控制         | 提交；确认；目录映射；问题导航；日志；搁置；Git；GitHub                                                                                                                                                                                                         |
| 项目结构         | 项目结构                                                                                                                                                                                                                                                        |
| 构建、执行、部署 | CMake；Gradle；Maven；控制台；调试器（数据视图、单步执行）；Python 调试器；运行/调试；运行目标；部署（选项）                                                                                                                                                    |
| 语言和框架       | 语言服务器；Go（构建标签、Go 模块）；Java；Markdown；Node.js；PHP；Python 解释器；Prettier；oxfmt；Ruff；Ruby；Rust；TypeScript                                                                                                                                 |
| 工具             | 智能体（聊天）；终端；保存时操作；外部工具；SSH 配置；MCP 服务器                                                                                                                                                                                                |
| 安全             | 项目信任                                                                                                                                                                                                                                                        |

已安装的插件可以添加设置页，带有可配置项的文件图标主题也会各自添加一页。插件的设置保存在 `[plugins.<plugin-id>]` 下。

## 常用配置键

### 顶层

| 键                | 默认值                                                     | 说明                                                                                                                                            |
| ----------------- | ---------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `keymap`          | macOS 上为 `intellij-macos`，其他系统为 `intellij-windows` | 当前快捷键方案：`intellij-macos`、`intellij-windows`、`vscode-macos`、`vscode-windows`、`eclipse-macos`、`eclipse-windows`，或自定义方案的 id。 |
| `keymapOverrides` | 空                                                         | 在内置方案之上，操作 id → 快捷键列表；空列表表示解除绑定。参见[键位映射](/zh/guide/keymap)。                                                    |
| `customKeymaps`   | 空                                                         | 你创建的方案：`name`、`parent`、`overrides`。                                                                                                   |

### `[general]`

除特别说明外，对应 设置 › 外观与行为 › 系统设置。

| 键                           | 默认值         | 说明                                                                                                                          |
| ---------------------------- | -------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `reopenLastProject`          | `true`         | **启动时重新打开项目**。                                                                                                      |
| `openProjectIn`              | `"ask"`        | 已有项目打开时，**打开…** 把新项目放在哪里：`ask`（询问）、`new`（新窗口）、`same`（当前窗口）或 `attach`（附加到当前项目）。 |
| `defaultProjectDirectory`    | `""`           | 打开和克隆对话框的初始文件夹；为空时使用系统默认位置。                                                                        |
| `saveOnIdle` / `idleSeconds` | `false` / `15` | **IDE 空闲以下时长时保存文件**，单位为秒。                                                                                    |
| `confirmExit`                | `true`         | **退出 IDE 前确认**。                                                                                                         |
| `closeWithoutWelcome`        | `false`        | **关闭窗口，而不是显示欢迎屏幕**。                                                                                            |
| `closeTabsWithWindow`        | `false`        | **关闭窗口时关闭所有编辑器标签页**。                                                                                          |
| `powerSaveMode`              | `false`        | **文件 › 省电模式**：不自动弹出提示，也不做后台高亮。                                                                         |
| `autoCheckUpdates`           | `true`         | **自动检查更新**（更新页）。                                                                                                  |
| `updateSource`               | `"auto"`       | **更新源**：`auto`、`github` 或 `cnb`。                                                                                       |
| `dateFormat.overrideSystem`  | `false`        | **覆盖系统日期和时间格式**（日期格式页）。                                                                                    |
| `dateFormat.pattern`         | `"dd.MM.yyyy"` | 日期格式，可用 `dd`、`MM`、`MMM`、`yy`、`yyyy`。                                                                              |
| `dateFormat.use24Hour`       | `true`         | 使用 24 小时制。                                                                                                              |
| `dateFormat.pretty`          | `true`         | 显示“今天”“昨天”“5 分钟前”这类相对时间。                                                                                      |

### `[appearance]`

| 键                                           | 默认值               | 说明                                                                                                                                                                                        |

| `contrastScrollbars`                         | `false`              | **使用对比度滚动条**。                                                                                                                                                                      |
| `redGreenVision`                             | `false`              | **针对红绿色觉缺陷调整颜色**。                                                                                                                                                              |
| `compactMode`                                | `false`              | **紧凑模式**。                                                                                                                                                                              |
| `showMainToolbar` / `showStatusBar`          | `true` / `true`      | **显示主工具栏**、**显示状态栏**。                                                                                                                                                          |
| `navigationBar`                              | `"statusBar"`        | **导航栏**：`top`、`statusBar` 或 `hidden`。                                                                                                                                                |
| `mainMenuStyle`                              | `"hamburger"`        | **主菜单**：`hamburger`（汉堡按钮）或 `merged`（与主工具栏合并）。                                                                                                                          |
| `ideAntialiasing` / `editorAntialiasing`     | `"greyscale"`        | `subpixel`、`greyscale` 或 `none`。                                                                                                                                                         |
| `locale`                                     | `"en"`               | **语言**（语言和地区页）：`en`、`zh`、`ko`、`fr`、`pl`、`pt`、`es`。                                                                                                                        |

| 键                                       | 默认值                           | 说明                                                                               |
| ---------------------------------------- | -------------------------------- | ---------------------------------------------------------------------------------- |

对应 设置 › 工具 › 终端。

| 键                                       | 默认值             | 说明                                                                |
| ---------------------------------------- | ------------------ | ------------------------------------------------------------------- |
| `shellPath`                              | `""`               | shell 命令行；为空时启动登录 shell。                                |
| `startDirectory`                         | `""`               | 起始目录；为空时为项目根目录，相对路径相对于项目根目录。            |

| `tabName`                                | `"Local"`          | 新标签页的名称。                                                    |

### `[proxy]`

对应 设置 › 外观与行为 › 系统设置 › HTTP 代理。IDE 自身的下载、更新程序和 HTTP 客户端都会使用；配置手动代理时，IDE 启动的进程会获得 `HTTP_PROXY`、`HTTPS_PROXY` 和 `NO_PROXY` 环境变量。

| 键                       | 默认值         | 说明                                                                                        |
| ------------------------ | -------------- | ------------------------------------------------------------------------------------------- |
| `mode`                   | `"auto"`       | `none`（直连）、`auto`（使用系统的 `HTTP_PROXY` / `HTTPS_PROXY` / `NO_PROXY`）或 `manual`。 |
| `kind`                   | `"http"`       | `http` 或 `socks`。                                                                         |
| `host` / `port`          | `""` / `80`    | 代理地址。                                                                                  |
| `noProxy`                | `""`           | 直连的主机，逗号分隔；`*` 匹配任意字符。                                                    |
| `authenticate` / `login` | `false` / `""` | 代理认证。密码保存在已保存的密码中，不写入 `settings.toml`。                                |
