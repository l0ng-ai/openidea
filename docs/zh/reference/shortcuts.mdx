下表是默认快捷键：macOS 上使用 **macOS** 方案，Windows 和 Linux 上使用 **Windows** 方案，两者都与 IntelliJ IDEA 一致。如果你切换到了 VS Code 或 Eclipse 方案，或者修改过快捷键，可以在 IDE 中通过 **帮助 › 快捷键参考** 查看当前生效的绑定，或在 **设置 › 按键映射** 中修改（参见[键位映射](/zh/guide/keymap)）。

macOS 符号：`⌘` Command、`⌥` Option、`⌃` Control、`⇧` Shift、`↵` Return、`⌫` Delete、`⌦` 向前删除、`⎋` Escape、`⇥` Tab。`⇧⇧` 和 `Shift Shift` 表示连按两下 Shift，`⌃⌃` 和 `Ctrl Ctrl` 表示连按两下 Control。列出两个快捷键时，任选其一即可。

有些快捷键的作用取决于焦点所在位置。例如 `⌘N` / `Alt+Insert` 在编辑器中是 **生成…**，在项目工具窗口中是 **新建**；`⌘R` / `Ctrl+F5` 在运行和调试工具窗口中重新运行所选配置。
