完整的发布说明、下载地址和校验文件见 [GitHub Releases](https://github.com/l0ng-ai/openidea/releases)。OpenIDEA 会自动更新，也可以手动执行 **检查更新**。

<Update label="0.1.40" description="2026-11-09">
  新增可选开启的内置 MCP Server、Ruby 调试、.NET 工作流、服务窗口中的 Docker 面板、附加项目，以及多个构建共享同一个 Java 语言服务器；切换编辑器标签页和长 Agent 对话更快；发布插件 API 1.4。

[发布说明](https://github.com/l0ng-ai/openidea/releases/tag/v0.1.40)

</Update>

<Update label="0.1.39" description="2026-11-08">
  新增开发容器、可编辑的数据库结果表格、Tomcat Server 运行配置、项目结构对话框、JetBrains 设置导入，并重做了 Agent 对话视图；发布插件 API 1.3。

[发布说明](https://github.com/l0ng-ai/openidea/releases/tag/v0.1.39)

</Update>

<Update label="0.1.38" description="2026-11-06">
  新增 Docker 和 Compose 运行目标、Oracle 数据源、Astro 支持、PHP 远程调试（含 PHPStan 和 PHP-CS-Fixer）、带覆盖率的 Ruby 测试运行，以及可选的更新源（含国内镜像）；发布插件 API 1.2。

[发布说明](https://github.com/l0ng-ai/openidea/releases/tag/v0.1.38)

</Update>

<Update label="0.1.37" description="2026-11-05">
  可以直接打开 WSL 项目、调试 Flutter 应用，新增 Diff 中的 Git Blame 和 Android Logcat 工具窗口；发布插件 API 1.1。

[发布说明](https://github.com/l0ng-ai/openidea/releases/tag/v0.1.37)

</Update>

<Update label="0.1.0 – 0.1.36" description="2026-10-22 – 2026-11-04">
  最早的几个公开版本，各版本的改动见 [GitHub Releases](https://github.com/l0ng-ai/openidea/releases)。
</Update>
