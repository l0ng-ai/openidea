## 选择主题

打开 **设置 › 外观与行为 › 外观**，在 **主题** 中选择。内置主题：

| 浅色                 | 深色           |
| -------------------- | -------------- |
| Islands 浅色（默认） | Islands 深色   |
| Solarized 浅色       | Solarized 深色 |
| One 浅色             | One 深色       |
|                      | 高对比度       |

已安装插件提供的主题也会出现在这个列表中，归在插件名下。

- **与操作系统同步**：跟随系统的浅色或深色模式。开启后 **主题** 列表不可选，改为在旁边的选项中通过 **操作系统浅色模式下的首选主题** 和 **操作系统深色模式下的首选主题** 分别指定。
- **视图 › 外观 › 切换浅色/深色主题**：在 Islands 浅色和 Islands 深色之间切换。
- **视图 › 快速切换方案…**（`` ⌃` `` / `` Ctrl+` ``）› **主题**：在列表中移动时即可预览主题。
- 欢迎屏幕的 **自定义** 页也提供同样的主题和强调色选择。

同一页面还有：

- **强调色**：界面的强调色。
- **不同的工具窗口背景**：让工具窗口与编辑器区分开。
- **辅助功能**：**使用对比度滚动条** 和 **针对红绿色觉缺陷调整颜色**（适用于红色盲和绿色盲）。
- **UI 选项** 下的 **紧凑模式**。

## 编辑器配色方案

编辑器的语法颜色来自配色方案。在 **设置 › 外观与行为 › 外观** 中，**编辑器配色方案** 默认为 **主题默认**，即当前主题自带的方案。如果希望换主题时编辑器颜色保持不变，可以选择其他内置方案或导入的方案。

在 **设置 › 编辑器 › 配色方案** 中编辑方案：

- 在树中选择一个元素，修改其前景、背景、粗体、斜体和效果。修改按方案分别保存，**恢复默认值** 可以撤销。
- **语言默认值** 中有 **语义高亮**（局部变量和参数按名称分配颜色）和 **彩虹括号**（按嵌套深度为括号着色）。
- **导入配色方案** 读取从 JetBrains IDE 导出的 IntelliJ 配色方案（`.icls`）。已有同名方案时，可以选择 **覆盖** 或 **保留两个**。**导出配色方案** 把当前方案导出为 `.icls`。

## IntelliJ 主题

IntelliJ 界面主题可以转换为 OpenIDEA 主题。打开一个项目后，进入 **设置 › 插件**，打开齿轮菜单，选择：

- **从 JetBrains IDE 导入主题…**：从本机 JetBrains IDE 已安装的主题插件中选择；或
- **从文件导入 IntelliJ 主题…**：选择主题插件的 `.jar`、插件市场下载的 `.zip`、插件文件夹或 `.theme.json` 文件。

OpenIDEA 会把主题（以及其中附带的编辑器配色方案）转换为主题插件并安装。当前使用的主题不会改变，需要在 **主题** 中选择新主题。

## 主题插件和图标插件

**设置 › 插件** 的插件市场中也有主题插件和文件图标主题插件。安装文件图标主题后，外观页面会出现 **文件图标主题** 选项。带有可配置项的图标主题会有自己的设置页。

想自己制作主题或图标主题，参见插件指南中的[主题](/zh/plugins/guides/themes)和[图标主题](/zh/plugins/guides/icon-themes)。

## 字体

### 编辑器字体

**设置 › 编辑器 › 字体**：

- **字体**：编辑器字体。勾选 **仅显示等宽字体** 可以缩小列表。默认字体是随 OpenIDEA 内置的 JetBrains Mono。
- **大小** 和 **行高**。
- **启用连字**：用于带编程连字的字体。
- **排版设置**：**主字重**、**粗体字重**，以及主字体缺少字符时使用的 **备用字体**。

临时调整字号可以用 **增大字体**（`⌥⇧.` / `Alt+Shift+.`）和 **减小字体**（`⌥⇧,` / `Alt+Shift+,`），用 **视图 › 重置所有编辑器中的字体大小** 恢复。在 macOS 上，开启 **设置 › 编辑器 › 常规** 中的 **使用 Command+鼠标滚轮更改字体大小** 后可以用滚轮缩放。

### 界面字体与缩放

在外观页面的 **辅助功能** 下：

- **使用自定义字体：** 设置菜单、工具窗口和对话框使用的 **UI 字体**、**UI 备用字体** 和字号。默认界面字体是 Inter。
- **缩放**：缩放整个 IDE。也可以用菜单 **视图 › 外观 › 放大 IDE**、**缩小 IDE** 和 **重置 IDE 缩放**（macOS 上为 `⌃⌥=`、`⌃⌥-`、`⌃⌥0`；Windows 和 Linux 上为 `Alt+Shift+=`、`Alt+Shift+-`、`Alt+Shift+0`）。

### 终端字体

终端默认使用编辑器字体。想单独设置终端字体，在 **设置 › 工具 › 终端** 中关闭 **使用编辑器字体**。
