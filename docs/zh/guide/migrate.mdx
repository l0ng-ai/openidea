OpenIDEA 沿用 IntelliJ IDEA 的模式：一个文件夹就是一个项目，各项功能放在工具窗口里，几乎所有操作都能通过随处搜索或查找操作找到。本页介绍哪些内容可以迁移过来，以及熟悉的功能在哪里。

## 选择快捷键方案

OpenIDEA 内置六套快捷键方案：

| 方案                                       | 来源                                                                        |
| ------------------------------------------ | --------------------------------------------------------------------------- |
| **macOS**                                  | IntelliJ IDEA 的 macOS 方案，macOS 上的默认方案。                           |
| **Windows**                                | IntelliJ IDEA 的 Windows 方案，Windows 和 Linux 上的默认方案。              |
| **VS Code (macOS)**、**VS Code (Windows)** | Visual Studio Code 的默认快捷键。VS Code 中没有快捷键的操作在这里也不绑定。 |
| **Eclipse (macOS)**、**Eclipse**           | IntelliJ IDEA 的 Eclipse 方案。                                             |

可以在以下位置切换：

- 欢迎屏幕 › **自定义** › **按键映射**
- **设置 › 按键映射**
- **视图 › 快速切换方案…**（`` ⌃` `` / `` Ctrl+` ``）› **按键映射**

可以在任意方案上修改单个快捷键，也可以复制一份作为自己的方案。参见[键位映射](/zh/guide/keymap)。

## 从 IntelliJ IDEA 及其他 JetBrains IDE 迁移

默认设置已经和 IDEA 一致：快捷键方案、工具窗口编号（`⌘1` / `Alt+1` 打开项目，`⌘9` / `Alt+9` 打开 Git）、`⇧⇧` / `Shift Shift` 打开随处搜索、`⌥↵` / `Alt+Enter` 显示上下文操作。

### 导入设置

使用 **文件 › 管理 IDE 设置 › 从 JetBrains IDE 导入设置…**，从本机找到的 JetBrains IDE 中选择一个。如果手上是从 JetBrains IDE 导出的 `settings.zip`，则选择 **文件 › 管理 IDE 设置 › 导入设置…** 并选中该 zip 文件。

修改生效前会弹出确认框，列出将要导入的内容：

- 配色方案（`.icls` 文件）以及当前使用的配色方案
- 编辑器字体：字体、字号、行距（换算为行高）和连字
- 去除行尾空格、保存时确保末尾换行、粘性行、显示空白字符、软换行
- **退出 IDE 前确认**

快捷键方案、代码样式、实时模板、检查配置和插件不会导入，确认框会列出被跳过的项。导入的值写入全局设置。

### 导入主题

打开一个项目后，进入 **设置 › 插件**，打开齿轮菜单，选择：

- **从 JetBrains IDE 导入主题…**：从本机 JetBrains IDE 已安装的主题插件中选择；或
- **从文件导入 IntelliJ 主题…**：选择主题插件的 `.jar`、插件市场下载的 `.zip`、插件文件夹或 `.theme.json` 文件。

主题会被转换为 OpenIDEA 主题插件并安装。之后在 **设置 › 外观与行为 › 外观 › 主题** 中选用。参见[主题与字体](/zh/guide/themes)。

### 导入运行配置

在查找操作中运行 **从 JetBrains 导入运行配置（.run、.idea）**，或使用 **运行 › 编辑配置…** 对话框中的导入链接。OpenIDEA 会读取项目 `.run` 和 `.idea` 中能够转换的运行配置，并通过通知告诉你导入了多少、其余的为什么没有导入。

### IdeaVim

Vim 模式会读取 `~/.ideavimrc`（或 `~/.openideavimrc`）。通过 **工具 › Vim** 开启。参见[Vim 模式](/zh/guide/vim)。

## 从 VS Code 迁移

把快捷键方案切换为 **VS Code (macOS)** 或 **VS Code (Windows)**，之后 `⇧⌘P` / `Ctrl+Shift+P` 打开查找操作，`⌘P` / `Ctrl+P` 打开转到文件，和你习惯的一样。

| VS Code         | OpenIDEA                                                                                            |
| --------------- | --------------------------------------------------------------------------------------------------- |
| 命令面板        | **查找操作**（默认方案中为 `⇧⌘A` / `Ctrl+Shift+A`）                                                 |
| 快速打开        | **转到文件**（`⇧⌘O` / `Ctrl+Shift+N`），或 **随处搜索**（`⇧⇧` / `Shift Shift`）                     |
| 资源管理器      | **项目** 工具窗口（`⌘1` / `Alt+1`）                                                                 |
| 问题面板        | **问题** 工具窗口（`⌘6` / `Alt+6`）                                                                 |
| 集成终端        | **终端** 工具窗口（`⌥F12` / `Alt+F12`）                                                             |
| 源代码管理      | **提交** 工具窗口（`⌘0` / `Alt+0`）和 **Git** 工具窗口（`⌘9` / `Alt+9`）                            |
| 扩展            | **设置 › 插件**                                                                                     |
| `settings.json` | **设置**（`⌘,` / `Ctrl+Alt+S`），保存在 `settings.toml`；项目级的值保存在 `.openidea/settings.toml` |
| `launch.json`   | 运行配置：**从 .vscode/launch.json 导入运行配置**                                                   |
| 多根工作区      | **文件 › 新建工作区…** 和 **附加项目…**                                                             |

项目中的 `.editorconfig` 会生效。VS Code 的设置和扩展不会导入。

## 从 Eclipse 迁移

把快捷键方案切换为 **Eclipse (macOS)** 或 **Eclipse**。

- **格式化器。** 想继续用 Eclipse 的 Java 格式化配置，打开 **设置 › 编辑器 › 代码样式 › Java**，把 **格式化方案** 设为 **自定义 Eclipse 格式化 XML**，然后选择导出的 XML 文件。
- **工作空间与项目。** Eclipse 在一个工作空间里打开多个项目；OpenIDEA 每个窗口打开一个项目。需要同时处理多个文件夹时，用 **文件 › 新建工作区…** 创建工作区，或用 **附加项目…** 添加文件夹。
- **透视图。** OpenIDEA 没有透视图。按自己的习惯摆放工具窗口，再用 **窗口 › 工具窗口布局 › 将当前布局另存为…** 保存。

## 概念对照

| 概念       | 在 OpenIDEA 中                                                                                |
| ---------- | --------------------------------------------------------------------------------------------- |
| 项目       | 你打开的文件夹。项目设置和共享的运行配置保存在其中的 `.openidea/` 文件夹。                    |
| 工具窗口   | 窗口边缘的面板：项目、Git、运行、调试、终端等，用对应的编号快捷键开关。                       |
| 操作       | 每个命令都是一个操作，可以在 **查找操作** 中运行，也可以在 **设置 › 按键映射** 中绑定快捷键。 |
| 运行配置   | 运行或调试什么、怎么运行，参见[运行配置](/zh/guide/run)。                                     |
| 语言服务器 | 为某种语言提供代码洞察的进程，参见[语言支持总览](/zh/languages/index)。                       |
