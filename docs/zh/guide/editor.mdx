编辑器的行为和默认快捷键沿用 IntelliJ IDEA。下文的快捷键在 macOS 上是 **macOS** 键位映射的默认值，在 Windows 和 Linux 上是 **Windows** 键位映射的默认值；任何一个都可以在 **设置 › 按键映射** 中修改（见 [键位映射](/zh/guide/keymap)）。所有命令也都能在 **查找操作**（`⇧⌘A` / `Ctrl+Shift+A`）里找到。

## 光标与选区

| 操作                       | macOS     | Windows / Linux    |
| -------------------------- | --------- | ------------------ |
| **添加或移除插入点**       | `⌥⇧`+单击 | `Alt+Shift`+单击   |
| **在上方添加光标**         | `⌥⌥↑`     | `Ctrl Ctrl+Up`     |
| **在下方添加光标**         | `⌥⌥↓`     | `Ctrl Ctrl+Down`   |
| **添加下一个匹配项到选区** | `⌃G`      | `Alt+J`            |
| **取消选择匹配项**         | `⌃⇧G`     | `Alt+Shift+J`      |
| **选择所有匹配项**         | `⌃⌘G`     | `Ctrl+Alt+Shift+J` |
| **在所选行末尾添加光标**   | `⌥⇧G`     | `Alt+Shift+G`      |
| **列选择模式**             | `⇧⌘8`     | `Alt+Shift+Insert` |
| **扩展选区**               | `⌥↑`      | `Ctrl+W`           |
| **缩小选区**               | `⌥↓`      | `Ctrl+Shift+W`     |

- **在上方 / 下方添加光标**：连按两下修饰键并按住不放，再按方向键。
- **添加下一个匹配项到选区** 第一次按下时选中光标处的单词，之后每按一次加入下一个匹配。找不到更多时会给出提示，再按一次就从文件开头继续找。
- 按住 `⌥` / `Alt` 拖动鼠标（macOS 和 Windows 上也可以用鼠标中键拖动）可以直接做矩形选区，不用切换模式。
- **扩展选区** 依据语法树逐级扩大到所在的单词、表达式、语句和代码块。

## 编辑行与代码

| 操作                                | macOS           | Windows / Linux                                |
| ----------------------------------- | --------------- | ---------------------------------------------- |
| **复制行或选区**                    | `⌘D`            | `Ctrl+D`                                       |
| **删除行**                          | `⌘⌫`            | `Ctrl+Y`                                       |
| **剪切到行尾**                      | `⌃K`            | —                                              |
| **上移行** / **下移行**             | `⌥⇧↑` / `⌥⇧↓`   | `Alt+Shift+Up` / `Alt+Shift+Down`              |
| **上移语句** / **下移语句**         | `⇧⌘↑` / `⇧⌘↓`   | `Ctrl+Shift+Up` / `Ctrl+Shift+Down`            |
| **向左移动元素** / **向右移动元素** | `⌥⇧⌘←` / `⌥⇧⌘→` | `Ctrl+Alt+Shift+Left` / `Ctrl+Alt+Shift+Right` |
| **使用行注释**                      | `⌘/`            | `Ctrl+/`                                       |
| **使用块注释**                      | `⌥⌘/`           | `Ctrl+Shift+/`                                 |
| **合并行**                          | `⌃⇧J`           | `Ctrl+Shift+J`                                 |
| **切换大小写**                      | `⇧⌘U`           | `Ctrl+Shift+U`                                 |
| **开始新行**                        | `⇧↵`            | `Shift+Enter`                                  |
| **在当前行前开始新行**              | `⌥⌘↵`           | `Ctrl+Alt+Enter`                               |
| **拆分行**                          | `⌘↵`            | `Ctrl+Enter`                                   |
| **补全当前语句**                    | `⇧⌘↵`           | `Ctrl+Shift+Enter`                             |
| **解包/移除…**                      | `⇧⌘⌦`           | `Ctrl+Shift+Delete`                            |
| **将文本光标移至匹配的大括号**      | `⌃M`            | `Ctrl+Shift+M`                                 |
| **将光标移至代码块开头** / **末尾** | `⌥⌘[` / `⌥⌘]`   | `Ctrl+[` / `Ctrl+]`                            |
| **将光标移至页面顶部** / **底部**   | `⌘⇞` / `⌘⇟`     | `Ctrl+PageUp` / `Ctrl+PageDown`                |
| **切换插入/改写**                   | `Insert`        | `Insert`                                       |

**将光标移至页面顶部** / **底部** 把光标放到编辑器完整显示的第一行 / 最后一行，保持所在列，不滚动视图；再加上 `⇧` / `Shift` 则选择到该处。

**剪切到行尾** 从每个光标剪切到所在行的行尾；光标后只剩空白（或光标已在行尾）时连同换行符一起剪切，所以在同一光标处再按一次会剪切下一行，这些连续的剪切合并为剪贴板中的一条内容。**删除到行首** 和 **删除到行尾** 以同样方式删除但不复制（删除到行首时，若光标在行首则删除前面的换行符），有选区时删除选区。除 Eclipse 键位映射（删除到行尾为 `⇧⌘⌦` / `Ctrl+Shift+Delete`）外，它们默认没有快捷键。

**贪婪退格** 一次删除每个光标前的所有空格、制表符和换行符，直到前一个非空白字符；光标前是其他字符或有选区时，它与 `⌫` / `Backspace` 相同。它默认没有快捷键。

**编辑 › 对行排序** 和 **编辑 › 反转行** 对选中的行（没有选区时为整个文件）重新排序，默认没有快捷键。对行排序按字符编码排序，大写字母排在小写字母之前。

**复制整行** 把光标或选区涉及的每一行完整复制到其下方（即使只选中了行的一部分），并让选区落在副本上。它默认没有快捷键，可在查找操作中运行，或在 **设置 › 按键映射** 中分配快捷键。

**填充段落** 将光标处的段落按硬换行列（**设置 › 编辑器 › 代码样式**）重新换行：一组连续的行注释、文档注释中直到下一个空行或 `@` 标签为止的 `*` 行，或纯文本文件中空行之间的各行。在代码中不执行任何操作。它默认没有快捷键。

**将缩进转换为空格** 和 **将缩进转换为制表符** 按编辑器的制表符宽度改写选中各行（没有选区时为整个文件）的行首空白；转换为制表符时，不足一个制表位的缩进保留为空格。它们默认没有快捷键，可在查找操作中运行，或在 **设置 › 按键映射** 中分配快捷键。

输入时括号和引号会自动成对，选中文本后输入引号或括号会把选区包起来。这些以及其他输入辅助（智能 Home、用 Tab 跳出右括号、在 `)` 前输入的 `;` 移到语句末尾、回车智能缩进、文档注释骨架、退格键如何处理缩进、粘贴时重新格式化）都在 **设置 › 编辑器 › 常规 › 智能键** 中。

## 剪贴板

| 操作                | macOS  | Windows / Linux    |
| ------------------- | ------ | ------------------ |
| **从历史记录粘贴…** | `⇧⌘V`  | `Ctrl+Shift+V`     |
| **粘贴为纯文本**    | `⌥⇧⌘V` | `Ctrl+Alt+Shift+V` |
| **复制引用**        | `⌥⇧⌘C` | `Ctrl+Alt+Shift+C` |
| **复制路径/引用…**  | `⇧⌘C`  | `Ctrl+Shift+C`     |

**从历史记录粘贴…** 按时间倒序列出当前窗口最近复制或剪切的 30 段文本。用 `↵` / `Enter` 粘贴选中项，`⌫` / `Delete` 删除选中的条目。历史只保存在内存中，关闭窗口后清空。

从编辑器复制时，剪贴板里还会带上富文本（保留语法高亮颜色）；不需要的话在 **设置 › 编辑器 › 常规 › 富文本复制** 中关闭。**复制为纯文本** 和 **复制为富文本** 以另一种格式复制一次选区，不更改该设置；编辑器的 **复制/选择性粘贴** 菜单只显示该设置未提供的那一项。它们默认没有快捷键。

## 代码折叠

| 操作                        | macOS              | Windows / Linux                 |
| --------------------------- | ------------------ | ------------------------------- |
| **折叠** / **展开**         | `⌘-` / `⌘=`        | `Ctrl+-` / `Ctrl+=`             |
| **全部折叠** / **全部展开** | `⇧⌘-` / `⇧⌘=`      | `Ctrl+Shift+-` / `Ctrl+Shift+=` |
| **递归折叠** / **递归展开** | `⌥⌘-` / `⌥⌘=`      | `Ctrl+Alt+-` / `Ctrl+Alt+=`     |
| **展开到级别** 1–5          | `⌘*` 后按 `1`–`5`  | `Ctrl+*` 后按 `1`–`5`           |
| **全部展开到级别** 1–5      | `⇧⌘*` 后按 `1`–`5` | `Ctrl+Shift+*` 后按 `1`–`5`     |
| **折叠代码块**              | `⇧⌘.`              | `Ctrl+Shift+.`                  |
| **折叠所选内容/移除区域**   | `⌘.`               | `Ctrl+.`                        |
| **自定义折叠…**             | `⌥⌘.`              | `Ctrl+Alt+.`                    |

所有折叠命令也在 **代码 › 折叠** 菜单中。可折叠区域来自语言的语法结构和 region 注释；**自定义折叠…** 用来跳转到文件中的自定义区域。打开文件时默认折叠哪些内容（文件头、导入、文档注释）在 **设置 › 编辑器 › 常规 › 代码折叠** 中设置。

**展开文档注释** / **折叠文档注释** 一次性展开或折叠文件中的所有文档注释（与该处 **文档注释** 选项针对的注释相同；文件头不受影响）。它们默认没有快捷键。

## 格式化

| 操作                | macOS  | Windows / Linux    |
| ------------------- | ------ | ------------------ |
| **重新格式化代码**  | `⌥⌘L`  | `Ctrl+Alt+L`       |
| **重新格式化文件…** | `⌥⇧⌘L` | `Ctrl+Alt+Shift+L` |
| **自动缩进行**      | `⌃⌥I`  | `Ctrl+Alt+I`       |
| **优化导入**        | `⌃⌥O`  | `Ctrl+Alt+O`       |

**重新格式化代码** 格式化选区，没有选区时格式化整个文件，整体算一步撤销。格式化由文件的语言服务器或该语言配置的格式化工具完成（例如 Python 用 Ruff，Web 语言用 Prettier、oxfmt 或 Biome；在查找操作里搜 **使用 … 重新格式化** 可以指定工具）。**重新格式化文件…** 还能选择范围并顺便优化导入。

缩进等代码风格选项在 **设置 › 编辑器 › 代码样式** 中，每种语言一个页面。项目里的 `.editorconfig` 也会生效。

想每次保存时自动格式化，在 **设置 › 工具 › 保存时操作** 中勾选 **重新格式化代码**（可同时勾选 **优化导入**）。保存时如何处理行尾空格和末尾换行，在 **设置 › 编辑器 › 常规** 的 **保存文件** 一节中设置。

## 标签页

| 操作                 | macOS | Windows / Linux |
| -------------------- | ----- | --------------- |
| **关闭标签页**       | `⌘W`  | `Ctrl+F4`       |
| **选择下一个标签页** | `⌃→`  | `Alt+Right`     |
| **选择上一个标签页** | `⌃←`  | `Alt+Left`      |
| **切换器**           | `⌃⇥`  | `Ctrl+Tab`      |

**窗口 › 编辑器标签页** 中还有 **固定标签页**、**关闭其他标签页**、**关闭所有标签页** 和 **重新打开已关闭的标签页**，默认都没有快捷键。在查找操作中运行 **将标签页移到新窗口**，可以把当前标签页拆到一个独立窗口。

标签页右键菜单中的 **关闭未修改的标签页**、**关闭除已固定外的所有标签页**、**关闭左侧标签页**、**关闭右侧标签页** 和 **关闭所有只读标签页** 也是作用于当前标签页及其所在组的操作：可在查找操作中运行，或在 **设置 › 按键映射** 中分配快捷键。已固定的标签页会保留。

标签页的位置、数量上限以及达到上限后的处理方式、预览标签页、排序方式，以及关闭标签页后激活哪一个，都在 **设置 › 编辑器 › 常规 › 编辑器标签页** 中设置。

标签页放在左侧或右侧时，标签页列的宽度随最长的名称变化，但不超过一个上限。拖动该列靠近编辑器的边缘（或聚焦后按 `←` / `→`）可以调整上限；调整对所有编辑器组生效，并会被记住。

## 拆分编辑器

| 操作                 | macOS | Windows / Linux |
| -------------------- | ----- | --------------- |
| **向右拆分**         | `⌘\`  | —               |
| **转到下一个拆分器** | `⌥⇥`  | `Alt+Tab`       |
| **转到上一个拆分器** | `⌥⇧⇥` | `Alt+Shift+Tab` |

**窗口 › 编辑器标签页** 中还有 **向下拆分**、**取消拆分**、**全部取消拆分**、**移动到另一组**、**在相对组中打开** 和 **更改拆分方向**。标签页右键菜单中的 **向右拆分并移动** 和 **向下拆分并移动** 会把当前标签页移到新的拆分中，它们也是操作：可在查找操作中运行，或在 **设置 › 按键映射** 中分配快捷键。所在组至少要有两个标签页。也可以把标签页拖到编辑区的某一侧边缘来拆分。在 Project 视图中，**在右侧拆分中打开**（`⇧↵` / `Shift+Enter`，右键菜单中也有）会把选中的文件打开到右侧拆分中。

## 显示选项

| 操作           | macOS | Windows / Linux |
| -------------- | ----- | --------------- |
| **增大字体**   | `⌥⇧.` | `Alt+Shift+.`   |
| **减小字体**   | `⌥⇧,` | `Alt+Shift+,`   |
| **滚动到中央** | `⌃L`  | `Ctrl+M`        |
| **向上滚动**   | —     | `Ctrl+Up`       |
| **向下滚动**   | —     | `Ctrl+Down`     |

**向上滚动** 和 **向下滚动** 把视图移动一行，光标保持原位，即使它因此移出可见区域。

- **视图 › 活动编辑器 › 软换行** 让当前编辑器的长行自动折行。想让某些文件类型默认软换行，在 **设置 › 编辑器 › 常规** 的 **软换行** 一节中设置。
- **视图 › 重置字体大小** 撤销当前编辑器或焦点区域的字体缩放（**视图 › 重置所有编辑器中的字体大小** 会重置所有打开的编辑器）。用 `⌘` / `Ctrl` + 鼠标滚轮调整字号的功能默认关闭，可在 **设置 › 编辑器 › 常规** 的 **鼠标控制** 一节中打开，并可选择作用于 **当前编辑器**（默认）或 **所有编辑器**。
- **视图 › 外观 › 进入无干扰模式** 隐藏工具窗口、标签页、状态栏和装订区域，并让正文居中。再执行一次即可退出。
- **显示行号**、**显示缩进参考线**、**显示粘滞行** 和 **显示空白** 在所有编辑器中打开或关闭对应显示。可从查找操作运行，或右键单击装订区域并打开 **外观**。
- 行号、空白字符、缩进参考线、光标样式和意图灯泡在 **设置 › 编辑器 › 常规 › 外观** 中设置。痕迹导航和粘滞行（滚动时把所在的声明固定在顶部）在 **设置 › 编辑器 › 常规** 下各有单独的页面。

## 保存

和 IntelliJ IDEA 一样，这里没有逐个文件保存的概念：切换到其他应用或内置终端时文件会自动保存，**文件 › 全部保存**（`⌘S` / `Ctrl+S`）立即保存所有文件。**设置 › 外观与行为 › 系统设置** 的 **自动保存** 一节还可以设置在 IDE 空闲一段时间后保存。

如果在保存期间继续编辑，未写入磁盘的改动仍会标记为未保存。

在 IDE 之外修改的文件，会在切回 IDE 窗口时同步。**从磁盘重新加载**（`⌥⌘Y` / `Ctrl+Alt+Y`）立即重新加载当前文件。
