## 切换语言

打开 **设置 › 外观与行为 › 系统设置 › 语言和地区**，在 **语言** 中选择：

| 语言                           | 设置值 |
| ------------------------------ | ------ |
| English（默认）                | `en`   |
| 简体中文 (Chinese, Simplified) | `zh`   |
| 한국어 (Korean)                | `ko`   |
| Français (French)              | `fr`   |
| Polski (Polish)                | `pl`   |
| Português (Portuguese)         | `pt`   |
| Español (Spanish)              | `es`   |

点击 **应用** 或 **确定** 后立即生效，包括系统菜单栏，无需重启。尚未翻译的文本保持英文。英文和简体中文是完整的，其他语言可能有部分缺失。

在 `settings.toml` 中，这个选项是 `[appearance]` 下的 `locale`：

```toml
[appearance]
locale = "zh"
```

OpenIDEA 会把当前界面语言告诉插件，插件如果自带翻译，就会用这种语言显示自己的文本。

## 用中文搜索

设置搜索、查找操作和随处搜索同时匹配英文名称和翻译后的名称，用中文或英文搜索都可以。

## 日期和时间格式

默认情况下，Git 日志、本地历史记录和 Blame 注解中的日期跟随操作系统的区域设置。想自己指定格式，打开 **设置 › 外观与行为 › 系统设置 › 日期格式**，开启 **覆盖系统日期和时间格式**。格式中可以使用 `dd`、`MM`、`MMM`、`yy` 和 `yyyy`。

## 更新源

**更新源** 为 **自动**（默认值）时，界面语言为中文则从 CNB 国内镜像下载更新，否则从 GitHub 下载。参见[安装](/zh/guide/install)。

## 参与翻译

翻译文件就在代码仓库中。添加或修正翻译，参见[文案与国际化](/zh/contribute/guidelines/i18n)。
