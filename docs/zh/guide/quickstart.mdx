本页带你从刚装好 OpenIDEA 到运行、调试一个项目。快捷键按默认方案列出：先写 macOS，再写 Windows 和 Linux。

## 打开项目

OpenIDEA 把一个文件夹作为项目打开，以下方式都可以：

- 在欢迎屏幕点击 **打开** 并选择文件夹，或直接把文件夹拖到窗口上。
- 使用 **文件 › 打开…**（macOS 上为 `⌥⇧⌘O`）。
- 在终端里进入该文件夹，运行 `openidea .`。参见[命令行](/zh/reference/cli)。
- 在欢迎屏幕点击 **克隆仓库**，或使用 **Git › 克隆…** 克隆一个仓库。

单独打开一个不属于任何项目的文件时，它会在没有项目的窗口中打开。在该窗口中点击 **作为项目打开**，即可把所在文件夹作为项目打开。

## 信任项目

第一次打开某个文件夹时，OpenIDEA 会询问 **信任并打开项目？** 加载、构建或运行项目可能会执行其构建脚本中的代码，所以只信任来源可靠的项目。

- **信任项目**：正常打开，所有功能可用。勾选 **信任此文件夹中的项目：** 可以同时信任上级文件夹中的所有项目。
- **以受限模式预览**：可以浏览、编辑和搜索文件，但语言服务器、构建、运行配置等项目命令都不会启动。窗口顶部会显示 **受限模式** 横幅，确认可信后点击其中的 **信任项目**。
- **不打开**：取消打开。

之后可以在 **设置 › 安全 › 项目信任** 中管理受信任的项目和文件夹。

## 等待索引

项目打开后，状态栏会显示 **正在编制索引** 任务以及文件数和符号数。按符号导航和代码洞察都依赖索引，所以这个任务不能取消；大多数项目几秒钟就能完成。

如果某种语言需要的语言服务器还没有安装，会弹出通知说明缺少哪个服务器，并提供 **安装** 按钮。语言服务器在 **设置 › 语言和框架 › 语言服务器** 中管理。各语言使用哪些工具，参见[语言支持总览](/zh/languages/index)。

## 查找

| 目的                                 | macOS | Windows / Linux    |
| ------------------------------------ | ----- | ------------------ |
| 搜索一切：文件、类、符号、操作、设置 | `⇧⇧`  | `Shift Shift`      |
| 按名称执行任意操作                   | `⇧⌘A` | `Ctrl+Shift+A`     |
| 转到类                               | `⌘O`  | `Ctrl+N`           |
| 转到文件                             | `⇧⌘O` | `Ctrl+Shift+N`     |
| 转到符号                             | `⌥⌘O` | `Ctrl+Alt+Shift+N` |
| 在整个项目中查找文本                 | `⇧⌘F` | `Ctrl+Shift+F`     |
| 重新打开最近的文件                   | `⌘E`  | `Ctrl+E`           |
| 转到光标处元素的声明                 | `⌘B`  | `Ctrl+B`           |
| 显示项目树                           | `⌘1`  | `Alt+1`            |

`⇧⇧` 表示连按两下 Shift。想找某个功能时，**查找操作** 最快：输入几个关键词即可。更多内容参见[搜索与导航](/zh/guide/search)和完整的[快捷键表](/zh/reference/shortcuts)。

## 运行

OpenIDEA 会识别项目中可以运行的内容，在入口函数和测试旁的边栏显示运行图标。

- 点击边栏图标并选择 **运行 '…'**；或者把光标放在代码中，按 `⌃⇧R` / `Ctrl+Shift+F10`（**运行上下文配置**）。
- 在工具栏中选择一个配置，按 `⌃R` / `Shift+F10` 再次运行。
- 按 `⌃⌃` / `Ctrl Ctrl`（**运行任何内容…**）按名称运行命令、脚本或任务。
- **运行 › 编辑配置…** 用于新建和编辑运行配置。

输出显示在 **运行** 工具窗口（`⌘4` / `Alt+4`）中，`⌘F2` / `Ctrl+F2` 停止进程。参见[运行配置](/zh/guide/run)。

## 调试

1. 在某一行旁的边栏中单击，或按 `⌘F8` / `Ctrl+F8`，设置断点。
2. 用 **调试**（`⌃D` / `Shift+F9`）或边栏图标中的 **调试 '…'** 启动配置。
3. 命中断点后，**调试** 工具窗口会显示调用栈和变量。用 `F8`（步过）、`F7`（步入）和 `⇧F8` / `Shift+F8`（步出）单步执行，用 `F9` 恢复运行（macOS 上也可以用 `⌥⌘R`）。
4. 用 `⌥F8` / `Alt+F8` 计算表达式。

如果该语言的调试器还没有安装，OpenIDEA 会提示安装，装好后再启动调试会话。参见[调试](/zh/guide/debugging)。
