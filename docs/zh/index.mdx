---

OpenIDEA 把 IntelliJ IDEA 的使用方式（快捷键、工具窗口、随处搜索的习惯）带到一个以 Rust 为核心的原生桌面应用里。支持 macOS、Windows 和 Linux，采用 Apache 2.0 许可证。

用过 IntelliJ IDEA、PyCharm 或其他 JetBrains IDE 的话，大部分经验可以直接沿用：连按两下 <kbd>Shift</kbd> 打开随处搜索，`⌥↵` / `Alt+Enter` 显示上下文操作，默认快捷键方案与 IDEA 一致。从 VS Code 或 Eclipse 过来，也有对应的内置快捷键方案。

## 亮点

- **一个 IDE 覆盖多种语言。** 为 60 多种语言提供编辑和代码洞察，项目需要的语言服务器可一键安装。参见[语言](/zh/languages/index)。
- **常用工具齐全。** 调试器、Git、终端、数据库客户端、HTTP 客户端、测试运行器、覆盖率和性能分析器，各有自己的工具窗口。
- **随处搜索。** 在已建立索引的项目中使用随处搜索、查找操作、转到类 / 文件 / 符号以及在文件中查找。
- **重构与检查。** 重命名、提取、内联、更改签名、安全删除、快速修复和代码检查。
- **远程开发。** 通过 SSH 或在开发容器中工作，后端是 `openidea-server`。
- **AI 智能体。** 在工具窗口中运行编码智能体，并通过内置 MCP 服务器把 IDE 自身的工具提供给它们。
- **插件。** 插件可以添加操作、补全、快速修复、工具窗口、自定义编辑器、主题、文件图标和语言。插件以沙箱化的 WebAssembly 组件运行；主题、图标主题和语言无需编写代码。插件 API 目前仍是预览版。

## 性能对比

在缓存已预热的情况下打开 [freqtrade](https://github.com/freqtrade/freqtrade)（Python，约 770 个文件），取 5 次运行的中位数：

|                       | OpenIDEA       | IntelliJ IDEA 2026.2.3 |
| --------------------- | -------------- | ---------------------- |
| 显示项目窗口          | **0.9 s**      | 3.1 s                  |
| 就绪（CPU 平稳）      | **1.1 s**      | 13.2 s                 |
| 内存（USS，所有进程） | **169 MB**     | 2011 MB                |
| 就绪前消耗的 CPU 时间 | **2.4 s**      | 47.9 s                 |
| 空闲 CPU              | 单核的 **4 %** | 单核的 7 %             |
| 退出                  | **0.3 s**      | 5.9 s                  |

测试使用 `main` 分支的 OpenIDEA release 构建，以及默认设置和插件的 IDEA，环境为 Windows 11、32 核 AMD、62 GB 内存。IDEA 对 Python 的分析更深入，所以两边的“就绪”并不代表完成了同样多的工作。两者都以相同方式从外部测量：可以用 [`perf/compare`](https://github.com/l0ng-ai/openidea/blob/main/perf/compare) 在自己的机器和项目上复现。
