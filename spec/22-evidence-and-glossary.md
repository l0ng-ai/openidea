# 22 — 证据、度量与术语

> 范围：本文档的取证方法、可复现的度量数据、模块与扩展点的实测分布、完整术语表、交叉引用索引、证据局限。｜ 依赖：全部。｜ 排除：不重复各子系统的设计结论。

## 1. 目的与范围

本规格的每一条结构性结论都来自对**已安装产品**的静态观测，而非文档转载。本文件的作用是让读者能**独立复核**每一个数字与每一处"存在性"断言。

不依赖网络、不依赖源代码仓库、不依赖任何外部资料。

## 2. 取证方法（可复现步骤）

### 2.1 观测对象

| 对象 | 位置 | 提供的证据 |
|---|---|---|
| 产品清单 | 安装根 `product-info.json` | 产品名/版本/构建号/产品代码/最低运行时/捆绑插件/公开模块标识/打包布局/处理的文件扩展名 |
| 模块描述符 | `modules/module-descriptors.jar`（2126 条目） | 2090 个模块的依赖边、命名空间、资源根 |
| 构件清单 | `lib/`（429 个 jar）、`plugins/`（164 个目录、1788 个 jar） | 模块的物理落点与第三方库构成 |
| 插件描述符 | 各 jar 内 `META-INF/plugin.xml`（168 份） | 插件 ID/名称/版本/依赖/不兼容声明/扩展注册/动作/文件类型 |
| 扩展点声明 | 各 jar 内 `META-INF/*.xml`（315 份模块级、170 份插件级含声明） | 3,235 个唯一扩展点的名称、区域、契约类型、动态性、属性约束 |
| 接口契约 | 反编译源码（18168 个源文件） | 服务的可声明维度、扩展点语义、启动相位、不变量 |
| 运行时形态 | 启动器与启动属性文件 | 堆上限、大文件阈值、循环缓冲、渲染管线开关 |

### 2.2 复现路径

1. 解压模块描述符归档，得到模块 → 依赖的有向图。
2. 遍历全部 jar，取出 `META-INF/plugin.xml` 与含 `<extensionPoint` 的 XML。
3. 解析插件描述符的 `<extensions>` 子元素，统计每个扩展标签的注册数与其提供者。
4. 解析扩展点声明，统计唯一名称、区域分布、动态性分布。
5. 对模块图做拓扑分析：回边计数、最长路径、反向依赖计数。
6. 选取平台核心构件做反编译，抽取接口字段与生命周期契约（**只取设计事实，不复制实现形态**）。

### 2.3 判定规则

- "存在"：在描述符或声明中被显式登记。
- "必须"：在接口契约或声明约束中被强制（类型约束、必填属性、相位注释）。
- `[推断]`：结构上高度一致但无直接声明，依同类系统经验补全，并在各文档 §12 汇总。

## 4. 术语表

规范写法，全文不得使用同义替换。

### 4.1 数据与结构

| 术语 | 英文 | 定义 |
|---|---|---|
| 虚拟文件 | Virtual File (VF) | 文件系统之上的统一文件标识与内容句柄 |
| 文档 | Document | 可编辑文本缓冲区，独立于 VF 存在，持有不可变快照 |
| 语法树 | Syntax Tree | 解析产生的带范围与类型的节点树 |
| 程序结构接口 | PSI | 语言无关的树/符号/引用访问层 |
| 桩 | Stub | 可脱离全文重建的语法树轻量片段，用于索引输入 |
| 语言注入 | Language Injection | 把一段文本区域视为另一种语言的完整文件 |
| 元素操纵器 | Element Manipulator | 文本片段 ↔ 结构化值的双向转换器 |
| 索引 | Index | 从内容/桩派生的持久键值映射 |
| 代际 | Generation | 派生数据的版本号，用于批量失效 |

## 6. 证据局限

1. **静态观测**：所有结论来自安装包静态结构，未运行产品，故不包含运行时性能数字（除启动参数给定的预算）。
2. **闭源内核**：核心模块反编译结果可读性有限（字段名/行号丢失），因此只采信**接口签名、常量、声明式约束**，不推断算法实现细节。
3. **动态行为**：调度顺序、缓存淘汰策略、UI 布局算法等只能从接口契约与相位命名推断，均在文档中以 `[推断]` 标注。
4. **产品定制层**：Ultimate 定制层（许可、试用、套件功能）与开源平台内核混杂在同一安装中，部分能力归属需按模块名判断，不作商业判断。
5. **语言插件规模**：Kotlin 等大型语言插件的实现体积过大，未做全量反编译，相关文档以扩展点声明与模块依赖为证据，语言内部实现标注为范围外。
6. **版本敏感性**：本规格绑定构建 `IU-262.8665.337`；模块数、扩展点计数、动作数在其他构建中会有差异，结构性结论（分层、相位、接缝）应保持稳定。
