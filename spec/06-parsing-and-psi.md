# 06 — 解析、语法树与程序结构接口

> 范围：文本到结构的转换（词法、语法、建树）、程序结构接口（元素、引用、符号、类型）、桩、语言注入、元素操纵。｜ 依赖：01、02、03、04、05。｜ 排除：索引的构建与存储（07）、高亮与检查（08）、补全与导航策略（09）、重构流程（10）。

## 1. 目的与范围

### 1.1 本子系统解决什么问题

把"字符缓冲区"变成"可查询的程序结构"，且必须同时满足四个彼此冲突的要求：**足够快**（键入路径不得触发全文解析，解析必须可取消、可分片，§4.4）；**足够省**（打开只被索引用到的库文件不得为读一个名字而解析全文，§4.7）；**足够通用**（十余种语言、多种混排形态共享同一套元素/引用/符号抽象，§2、§4.8）；**足够开放**（第三方可在不改核心的前提下补词法、引用、符号、注入与值转换，§10）。

由此确定三段式职责：

- **解析**：纯函数，文本 → 树；不得有跨文件语义，不得访问索引。
- **程序结构接口（Program Structure Interface，下称 PSI）**：树的类型化视图 + 元素层次 + 引用图 + 符号与类型抽象；可跨文件、可访问索引，但必须能降级。
- **桩（Stub）**：PSI 的可持久化摘要，使索引无需全文树即可工作（§4.7）。

### 1.2 边界

不负责：文件内容来源与编码（见 04）；缓冲区编辑模型（见 05）；索引键值布局与持久化（见 07，本文只规定"桩如何成为索引输入"）；具体语言的语法与类型规则；格式化引擎（只规定"记号间是否必须存在空白"的声明）。

### 1.3 与其他子系统的关系

| 关系 | 说明 |
|---|---|
| 04 虚拟文件 | 解析输入是文件内容；文件标识决定结构缓存的作用域 |
| 05 文档/编辑器 | "缓冲区→树"的提交是增量重解析的触发点 |
| 07 索引 | 消费桩与轻量树，不消费全文树 |
| 08 分析 | 消费引用解析结果；未解析引用是问题来源之一 |
| 09 导航 | 消费"名字→目标"；元素身份稳定性决定导航结果可否缓存 |

## 2. 概念模型

### 2.1 五个层次

| 层 | 单位 | 归属 | 可持久化 |
|---|---|---|---|
| 文本 | 字符缓冲区 | 文档 / 文件内容 | 是（用户数据） |
| 词法单元 | 记号：类别 + 起止偏移 | 一次词法遍历 | 否 |
| 树 | 树节点（复合/叶子/惰性） | 文件，按语言各一棵 | 否，可整体重建 |
| 程序结构 | 元素：节点的类型化投影 + 语义操作 | 文件 | 否 |
| 符号与类型 | 声明、符号、类型 | 项目 | 否，由元素派生 |

**关键区分**：树是"语法事实"，元素是"语义视图"。同一文本可按不同语言视角暴露不同元素集合（§4.2、§4.8），但每棵树上只有一套节点。

### 2.2 核心实体与关系

| 实体 | 定义 |
|---|---|
| 语言（Language） | 有稳定标识与可选 MIME 集合的语法/语义单元；可声明基语言形成方言链 |
| 元语言（Meta Language） | 由另一层描述（文法/模式）定义的语言，用于"匹配一族语言"；不得作基语言 |
| 文件类型（File Type） | 文件级分类：扩展名、是否二进制、是否只读、可选关联语言 |
| 解析定义 | 语言登记词法、语法、文件节点、记号类别、元素与文件构造入口的唯一接缝 |
| 树节点 / 元素 | 节点是有类别与范围的语法单元；元素是其类型化包装，提供导航与语义操作 |
| 引用 / 符号声明 | 引用是"元素内一段范围→一个目标或一组符号"；声明是"某范围内的符号" |
| 类型（Type） | 独立于元素身份的语义对象：可否赋值、成员、父类型 |
| 桩（Stub） | 元素层次的轻量摘要，携带重建元素所需的最小字段 |
| 宿主 / 注入片段 | 宿主是能承载注入的元素（负责映射与转义）；片段是宿主内区间 + 注入侧映射 + 前后拼接文本 |

```
语言 --声明--> 解析定义；文件类型 --关联--> 语言 --方言链--> 基语言
文件视图 ==按语言持有==> 树 / 桩树；树 --投影--> 元素；桩树 --重建--> 元素
元素 --> 引用 --> 符号 <-- 符号声明 <-- 元素
符号 --具有--> 类型；元素 --充当--> 宿主 --生成--> 注入文件
```

### 2.3 三组必须分清的概念

1. **树节点 ≠ 元素**：节点可脱离元素存在（轻量树只有节点、无元素，§4.7.1）；元素必须依附节点。生成、回放、比较针对节点；导航、解析、重命名针对元素。
2. **文本偏移 ≠ 元素身份**：身份在生命周期内稳定，偏移随编辑变化；不得以偏移作跨编辑的键（§4.4.4）。
3. **桩 ≠ 精简版全文树**：桩只保留索引与跨文件解析所需字段，故某些元素的子节点在桩视图下"尚未可知"（§4.7.5）。

## 4. 行为契约

### 4.1 语言注册

1. 语言以**标识**注册；重复标识或重复实现类必须立即失败，不得"后者覆盖"。MIME **多对多**：同一 MIME 可映射多个语言，注册顺序必须保留，后续按序择一。
2. 声明基语言即建立**方言链**；注册方言必须把它加入**每个祖先**的传递闭包。族属判定沿链向上匹配，故"语言 X 的扩展对 X 的所有方言生效"是默认语义，不是特例。
3. **元语言不得作基语言**：若基语言是元语言，注册必须被拒绝。另存在"任意语言"占位，可用于"对所有语言生效"的查询，但它**不得**作为解析目标或替换器返回值。
4. 注销语言必须级联：注销其节点类型、清空以它为键的引用提供者缓存、从基语言的方言集合移除、使所有"按语言键缓存"的查询结果失效。

### 4.2 文件 → 语言判定

```
languageOf(file, project):
  1 内存文件且显式声明语言 → 用之（跳过 2、3）
  2 lang := 文件类型关联语言
  3 依次询问"任意语言"键的替换器；首个非空且非占位结果即采用
  4 依次询问 lang 键的替换器；首个结果即采用
  5 若最终语言 ≠ 文件类型语言 → 写入项目级文件属性，并**请求重解析**
  6 返回 lang
```

- 替换器返回"任意语言"视为实现错误：记录并忽略。判定结果按（文件标识、项目、文件类型）缓存；内容变化不影响判定，除非替换器显式声明依赖内容。
- 一个文件类型只有**一个主语言关联**：多个声明时取第一个"非次生"类型；否则取第一个"其语言是目标语言后代"的次生类型。
- 判定不出语言时文件以**纯文本视图**存在：可编辑、可搜索、不解析——这是合法状态（D0），不是降级。

### 4.3 三阶段流水线

**4.3.1 词法** —— 输入为缓冲区（或子区间）+ 起始偏移 + **初始词法状态**，输出记号流；遍历器必须可在任意位置恢复，`(offset, state)` 是完整恢复点。平台只强制三类**必须显式声明**的记号集合，且它们不是装饰性信息：**空白**决定建树是否保留节点并提供"两记号间是否必须补空白"的判定输入；**注释**决定其是否参与结构；**字符串字面量**决定元素操纵与注入能否安全转义取值（§4.9）。**错误记号**：语言可把"无法识别的字符"定义为正式记号类别而非异常——词法层不产生异常，且必须保证后续阶段总能前进。**增量词法**由三处保证：`(偏移,状态)` 恢复只重扫编辑点附近；惰性子树在展开前不参与词法；仅空白变化时允许只替换空白记号而不重跑语法（接缝由平台提供，默认关闭）。词法阶段**必须不**访问文件系统、索引或其他元素。

**4.3.2 语法与错误恢复** —— 分析器由**构建器**驱动：

| 操作 | 语义 |
|---|---|
| 开启候选 | 在当前位置开一个未完成的候选节点 |
| 前进 | 消费一个记号；**不可回退** |
| 回滚至候选 | 放弃候选节点并丢弃其消耗的记号——唯一合法回退方式 |
| 完成（类别, 候选） | 关闭候选节点，范围 = 起始位置到当前位置 |
| 报错（文本, 候选） | 在起始位置产出**错误节点**，范围为空或覆盖已消费记号 |
| 结尾判定 | 是否到达输入末尾 |

错误恢复必须二选一且必须显式：**错误节点包围**（默认，把无法解析的序列包进错误节点，其范围即不可解析区）或**同步点跳跃**（丢弃记号至同步集合再继续，被丢弃区间仍必须产出错误节点）。

**不可解析区（unparsable region）的契约**：必须在树中有对应节点（不得"缺失节点"）且范围非空、覆盖被丢弃文本；必须是**局部**的——解析完一个区后必须继续，不得中止整棵树；文件根节点范围必须覆盖整个输入，任何字符都归属于某叶子或不可解析区（INV-4）；解析**永远不**把异常抛给调用方——内部异常必须被捕获并退化为"整文件为单个不可解析区"（§7）。递归下降与表驱动皆可实现：平台只规定"构建器 + 上述恢复策略"的接缝，不规定算法；由文法自动生成的分析器同样经此接缝接入。

**4.3.3 建树** —— 节点分三类：**复合**（范围由子节点并集决定）、**叶子**（有文本无子节点）、**惰性**（持原文，可延迟展开为子节点列）。惰性节点是**规模控制的核心**：文件初始只解析顶层，内层（函数体、表达式、模板片段）保持惰性，被访问时才展开，且**必须使用该节点所属语言的解析定义**而非父节点语言——这是嵌套语言的通用机制。文本映射：叶子持文本且相同文本**必须**驻留去重（"相等文本 = 相同引用"，子树比较退化为引用比较）；节点偏移为绝对偏移，相对父偏移由减法得出、不单独存储；元素范围 = 节点范围。建树必须保持兄弟节点范围不重叠、按序递增、并集等于父范围（INV-3）。元素构造是**惰性**的：节点存在不代表元素已构造，元素在首次访问时按节点类型映射并缓存回节点。

### 4.4 树的生命周期与增量重解析

**4.4.1 状态机**

```
未解析 ──首次访问──> 部分解析(含惰性子树) ──展开──> 完全解析
   │                        └──编辑落在本子树──> 重解析该子树
   └──桩可用──> 由桩重建元素（不建树）
```

文件级状态与元素状态独立：同一文件可处于"有桩无树""有桩有部分树""无桩有完整树"三种形态。桩与树可同时存在，但**树被完整构建后桩必须被丢弃**（树更精确；保留桩会产生两个真相）；反之树不得在桩未过期时被部分重建。惰性节点必须记录"是否已展开"，且该状态按快照版本独立判定。

**4.4.2 脏区计算与重解析边界**

```
onContentChanged(file, delta):
  1 delta 只落在单个惰性子树内且该子树支持增量重解析 → 只标记该子树为脏
  2 否则 → 把能覆盖全部变更的**最小祖先**标记为脏（向上扩到最近的可重解析单元）
  3 变更涉及整行增删且语言声明对行结构敏感 → 向上扩到文件根
  4 无法计算（整文件替换）→ 根即为脏区
```

**可重解析单元**由语言声明（通常是"平衡括号结构"或"语句"）；不声明时边界默认为**文件根**（安全但昂贵）。重解析必须**从脏区起点、以同样的初始词法状态**开始；脏区之前的节点复用，之后仅在偏移平移且内容未变时复用。复用判据是**结构相等**而非文本相等，且复用必须保留元素身份，否则外部持有的元素失效（INV-8）。

**4.4.3 提交：变更日志 + 单次事务**

```
commit(document):
  1 取缓冲区差异（编辑事件已给出，无需重新 diff 全文）
  2 为每个受影响子树产生一条变更记录：替换节点 / 替换子树（旧根子节点作为复用来源）
    / 替换整个文件节点
  3 在**一次**写事务内应用全部记录，汇总为一个树变更事件（变更根元素；每个受影响元素
    及其变更类型：属性/子节点/子树）
  4 提交后通知订阅者（分析、折叠、结构视图、版本控制标注）
```

**一条编辑 = 一次事务**，不得出现可见的半修改中间态；变更事件必须**可归约**（同一元素在一事务内的多次修改合并为一条）。**变更前置处理器**可在第 3 步前否决或改写变更（用于保持定界符配对等结构不变式）；变更后监听器只读，不得再触发写。

**4.4.4 版本标记与并发读取** —— 平台维护单调递增的**结构版本号**，每次写事务提交推进一次。每个元素记录**创建版本**；在低于创建版本的快照中访问该元素必须失败（它在请求的快照中尚不存在）。**冻结版本区段**内看到的版本视图不变，即使并发写已提交；该区段必须显式标注且不得发起写。只读快照必须自洽（同一父节点的子节点范围连续），**不得**把不同版本的节点混拼成一棵树——混拼必须被检测并拒绝（§7、§9）。**必须不**在写事务外修改树；从只读侧发起的修改必须先升级写意图（见 03 §4）。

### 4.5 引用与解析

**4.5.1 两种引用模型**：单目标引用（目标基数 0 或 1；软引用未解析不报错、硬引用报"未解析"；用于名字→声明、路径→文件、URL→端点）与符号引用（目标基数 0..n，未解析返回空集合由上层决定是否报错；用于一名多义：重载、多声明、多框架实体）。两者并存且必须互操作：符号引用必须能被用法查找、重命名、导航消费，而不要求其目标是一个具体元素。

**4.5.2 引用贡献者**

```
referencesOf(element):
  1 取该元素语言（及全部基语言）注册的提供者，按（元素类型模式，顺序）排序
  2 逐个调用收集；单个提供者异常 → 跳过并记录，不得中断
  3 追加隐式引用（无文本区间的语义引用，如由注解隐含的依赖）
  4 追加符号引用提供者的结果
  5 归一化：重叠区间合并，同一区间只保留最具体的引用
```

引用**必须**只依赖元素自身与其可见上下文，提供者内不得做跨文件全量搜索（昂贵操作由上层批量处理）；提供者**必须不**在"贡献引用"期间递归触发引用查询——平台以运行期断言检测这种递归。结果按元素缓存，失效条件是**全局结构版本变化**而非"本文件变化"（引用可指向任意文件）；返回给调用方的必须是**副本**，防止污染缓存。

**4.5.3 解析作用域**

| 作用域 | 边界 | 数据来源 |
|---|---|---|
| 词法 | 当前文件（含注入片段） | 树 + 局部声明 |
| 模块 | 一个编译/依赖单元 | 工作区模型（见 11） |
| 项目 | 项目内全部内容根 | 项目索引视图（见 07） |
| 库 | 依赖构件、SDK、共享索引 | 库桩 / 共享索引（见 07） |

从词法到库是**逐步扩大**：解析必须先在最小作用域尝试，未命中才扩大。作用域可被第三方扩大或收窄，但必须声明代价等级，且不得把词法级解析变成项目级扫描。每个文件有一个**解析范围**（可见模块 + 依赖闭包 + 库），由工程模型提供并在同步后失效。

**4.5.4 缓存与失效** —— 缓存键 =（引用所在元素身份，解析范围标识，结构版本）。失效层次：元素失效 → 其引用全失效；文件结构变更 → 该文件内引用失效，跨文件引用仅在其目标所在文件变更时失效（依赖"目标→反向依赖"记录）；工程模型变更 → 全部失效；索引就绪状态变化 → 所有"因索引缺失而降级"的结果必须失效重算。缓存**必须不**跨写事务强引用目标，使用可失效句柄。

**4.5.5 未解析引用的降级**

```
resolve(reference):
  1 作用域内命中 → 返回目标
  2 索引不可用（哑模式） → 只做词法级解析；无法判定时返回"未知"而非"未解析"
  3 目标文件未被索引（大文件/二进制/被排除） → 返回"未知"，不报未解析
  4 全部失败 → null；软引用静默；硬引用产生"未解析"诊断，并由未解析修复提供者给出候选修复
```

**必须区分"未解析"与"未知"**：前者是用户代码的问题（可诊断、可修复），后者是系统能力受限（不得报错、不得缓存为最终结果）。这是哑模式与索引部分可用时的核心契约（对应 01 §7 的 D1）。

### 4.6 符号与类型

- **声明**：元素内一段范围声明一个符号；同一符号可有多处声明（接口与实现、多模块重复声明）。**符号**独立于元素身份，可被多次声明与引用，也可以不对应任何元素（框架配置中的隐含实体）。
- **类型抽象**必须回答四问：可否赋值到目标类型、成员集合、父类型集合、是否等价；类型**不要求**由元素实现。**继承/实现关系**以"子类型→父类型"有向边表达，允许跨语言，允许未知（外部构件未提供层级信息）。
- **跨语言统一视图**分两条独立机制，二者都存在且不得互相依赖：**统一语法树**把不同语言的同构表达式（调用、字面量、控制流）映射为统一节点，供与语言无关的分析使用（实测注册 5 处，仅少数语言提供）；**统一符号模型**把不同语言/框架的声明统一为带上下文与查询配置的符号，供补全、文档、检查共用，并支持"在哪些语言启用""查询作用域贡献""声明提供者"。
- 选择规则：需在**表达式内部**跨语言分析时用统一语法树；只需"名字→实体"视图时用统一符号模型。

### 4.7 桩

**4.7.1 存在理由** —— **免全文解析**：从**轻量树**（只有节点、无元素）直接生成桩——走一遍词法与语法但不构造元素对象，实测路径即"文件节点未展开时用轻量解析生成桩树"；**可序列化**：桩可落盘随索引加载，冷启动无需重解析；**可快速定位**：桩树附带**脊**（按类型组织的扁平桩列表），"某类型的子桩"查询不必遍历整棵树。

**4.7.2 生成与一致性**

```
stubOf(file):
  1 文件类型不允许桩（二进制/超限/显式排除） → 无桩
  2 已落盘桩版本 == 当前语言桩版本 → 反序列化
  3 否则 → 用轻量树生成桩树 → 序列化 → 落盘
```

桩与树对同一文件**必须**产生相同元素骨架（类型、顺序、范围）。不一致（旧版本桩、两条代码路径产生的桩、多项目共享同一文件的状态冲突）必须被检测并报错；错误负载必须含：从索引读到的桩、桩列表长度是否相等、该文件缓存中的元素个数、桩树文本打印。检测到不一致后**丢弃桩并强制全文重建**，不得"用桩修补树"。

**4.7.3 版本与重建** —— 每语言有一个**桩版本整数**（由语言桩定义声明），另有**模板语言桩基版本**，仅在文件使用混排模板时参与版本计算。版本单调：任何影响桩内容的改动（字段集合、序列化格式、语义规则）都必须递增；版本变化意味着该语言**全部文件桩重建**，代价线性于该语言文件数，必须体现在诊断中。桩索引版本**等于**其依赖语言的桩版本：桩变则索引变，无需单独维护。

**4.7.4 序列化契约** —— 每个桩元素类型必须有一个**外部标识**（字符串），跨版本、跨进程稳定，不得由类名、内部序号或注册顺序派生。外部标识必须在**索引初始化完成之前**全部登记，且必须显式列在"桩元素类型持有者"声明中（实测 13 处）；未登记的类型若在索引完成后才被创建 → 视为实现错误并报出，因为它会让已落盘桩无法反序列化。桩字段必须由"字段序列化器"声明类型与顺序，**必须不**序列化元素引用、全文文本、跨文件信息。格式必须自描述到"外部标识 + 字段"，使未知类型可安全跳过（向前兼容读取）；**不保证**向后兼容——旧版本读新桩允许失败，此时按版本重建。

**4.7.5 桩的边界**

| 类别 | 规则 |
|---|---|
| 二进制文件 / 超大文件 | 不得有桩（反编译结果是桩的另一种来源，属例外）；超大文件由独立大小判定，比"可打开上限"更严 |
| 被排除的文件类型 | 不得进入共享索引，也不得生成可序列化桩 |
| 预置桩 / 注入文件 | 允许随构件发布预置桩；注入文件一律不生成桩、不参与全项目索引（§4.8.4） |

### 4.8 语言注入

**三种混排形态必须先分清**：**多根视图**（一个文件内容、每种语言各一棵完整树，产物为多个根元素共享同一缓冲区）；**模板语言**（一棵主树 + 外层语言占位节点 + 修补器，产物为单一根元素且外层片段被显式标记）；**注入**（宿主内一段区间映射为一个独立文件，产物为注入文件 + 区间映射表）。

**4.8.1 宿主资格与区间映射** —— 只有声明为宿主的元素能承载注入；宿主必须回答：是否有效、文本是否单行、如何转义、如何更新文本。**映射必须双向**（注入偏移↔宿主偏移），且不是恒等变换——转义序列、拼接前缀、拼接后缀都会破坏恒等性。映射输入是"宿主内的相关区间"（去掉引号、前缀等非值部分），因此同一宿主可只把值部分暴露给注入语言。

**4.8.2 声明与执行**

```
injectFor(host):
  1 单宿主：宿主语言声明的注入器给出（语言, 区间）
  2 多宿主（跨多个宿主合并）：
      startInjecting(language)
        addPlace(prefix, suffix, host_i, range_i)     // 可多次，跨不同宿主
      doneInjecting()
  3 由注入执行器按语言选择策略（是否为主执行器、是否降级）
  4 若存在用户可声明的注入配置，配置优先于代码注入
```

**多宿主**把多个不相邻宿主区间合并成**一个**注入文件，每段带自己的前后拼接文本，使"拼接后的 SQL/正则/路径"可被整体分析；**拼接感知注入**另允许把多段视为一个逻辑输入（独立接缝）。注入可**递归**（注入文件中的元素也可为宿主），必须设深度上限并检测循环（§8）。**抑制器**可按文件类型/上下文阻止注入，且抑制优先于注入。

**4.8.3 编辑同步** —— 注入文件的文本不是独立缓冲区，而是宿主缓冲区的**窗口**：读映射到宿主文档，写回写并转义。宿主文档每次变更后，落在受影响区间的注入文件必须失效重建，区间外的必须保留。窗口必须声明**可编辑片段**：只有值区间可编辑，引号与前缀不可编辑，对不可编辑区的编辑必须被拒绝或扩展到最近可编辑片段。允许**冻结窗口**：固定当前映射供异步分析；冻结后若宿主变更，冻结副本仍可读但**不得写回**。片段必须持有宿主缓冲区的**区间标记**而非裸偏移，标记失效即片段失效——这是编辑后不出现"错位注入"的唯一保障。

**4.8.4 边界与性能上限** —— 注入必须先做"该偏移是否可能有注入"的快速判定再定位，不得为回答"此处有无注入"而枚举全部注入。深度、注入文件数/宿主数、注入后总文本长度都必须有上限；超限时**保留最外层**、丢弃内层并记录原因。注入文件不生成桩、不进入全项目索引，其分析结果仅在宿主所在文件的作用域内有效。

### 4.9 元素操纵：文本 ↔ 值

每个可被"按值修改"的元素必须回答**值区间**（不含引号、前缀、修饰）与**替换操作**；两个入口都必须支持：元素内区间 + 新文本的原地替换（局部编辑），元素 + 新值的按值替换（重命名、字面量编辑、批量变换）。**转义与引号**：若元素是字符串字面量（由语言的字符串字面量记号集合声明），替换必须经宿主转义器——先解码取值再编码写回；值区间必须排除引号；值中出现定界符时编码器必须转义而非截断；编辑器层的引号配对/跳出由语言的引号处理器声明，**不得**由元素层实现。替换必须可预测且幂等（连续两次替换为相同值，树结构相同），且必须走写事务（§4.4.3），不得直接改写叶子文本。若元素无法表达某值（枚举字面量、受限语法），替换必须**失败**并给出可捕获原因，**不得**产生新的不可解析区。

## 5. 不变量与约束

| 编号 | 不变量 |
|---|---|
| INV-1 | 语言标识全局唯一；重复注册必须失败而非覆盖。 |
| INV-2 | 元语言不得作为任何语言的基语言。 |
| INV-3 | 同一父节点的子节点范围互不重叠、按序递增、并集等于父范围。 |
| INV-4 | 文件根节点范围覆盖整个输入；任何字符归属于某个叶子或不可解析区。 |
| INV-5 | 词法遍历器只前进；回退只能通过候选节点回滚实现。 |
| INV-6 | 解析阶段不得访问索引、文件系统或任何跨文件状态。 |
| INV-7 | 解析器异常不得传播给调用方，必须退化为"整文件不可解析区"。 |
| INV-8 | 增量重解析后，未被替换的元素身份必须保持不变。 |
| INV-9 | 一次编辑对应恰好一次树变更事务，且无可见中间状态。 |
| INV-10 | 元素只能在其创建版本及之后的结构版本中访问。 |
| INV-11 | 引用缓存按全局结构版本失效，返回结果必须是副本。 |
| INV-12 | "未解析"与"未知"必须区分；哑模式下不得把"未知"缓存为最终结果。 |
| INV-13 | 桩与树对同一文件必须产生相同元素骨架；不一致必须检测并重建。 |
| INV-14 | 桩元素类型的外部标识必须在索引初始化完成前全部登记。 |
| INV-15 | 注入片段必须持有宿主缓冲区区间标记；标记失效即片段失效。 |
| INV-16 | 元素替换不得产生新的不可解析区；无法表达的值必须拒绝。 |
| INV-17 | 树被完整构建后，同一视图中的桩必须被丢弃。 |
| INV-18 | 语言注销必须级联清理节点类型、引用提供者缓存与按语言键的扩展缓存。 |

## 7. 故障模式与降级

| 故障 | 检测 | 用户可见 | 降级 | 档位 |
|---|---|---|---|---|
| 词法/语法错误 | 存在错误节点 | 不可解析区高亮 | 局部不可解析，其余可用 | D0 |
| 解析器实现异常 / 词法不前进 | 解析入口捕获 / 偏移未推进 | 该文件"无法建立结构" | 整文件退化为纯文本结构 | D2 |
| 桩版本不匹配 | 版本比对 | 无（后台重建） | 丢弃旧桩，全量重建该语言桩 | D1 |
| 桩与树不一致 | 骨架比对 | 内部错误报告 + 诊断包 | 丢弃桩，强制全文重建该文件 | D1 |
| 桩反序列化失败（未知外部标识） | 反序列化期 | 索引不完整提示 | 跳过该桩，按需重建 | D1 |
| 引用提供者异常 / 引用解析递归 | 逐提供者捕获 / 运行期断言 | 该位置无解析、内部错误报告 | 跳过该提供者或中断递归，返回未解析 | D2 |

| 注入循环 / 映射失效 | 宿主链检测 / 区间标记失效 | 内部错误报告；注入高亮短暂消失 | 截断注入链；重建注入文件 | D2 / D0 |
| 语言重复注册 | 注册期比对 | 插件加载失败通知 | 拒绝该语言，其余语言可用 | D2 |
| 版本化快照混拼 | 一致性校验 | 内部错误报告 | 丢弃快照，重读当前版本 | D2/D3 |
| 文件超阈值 | 大小比对 | "大文件，仅纯文本" | 关闭解析/桩/索引 | D1 |
| 桩存储损坏 | 读取校验 | 通知"索引重建中" | 全量重建 | D5 |

## 8. 资源与性能预算

| 项 | 预算 / 实测 |
|---|---|
| 声明的解析定义 / 文件类型 | 146 个 / 172 个（实测，含模块与插件描述符）；处理扩展名 250 个 |
| 全功能文件大小上限 | 2.5 MB（实测配置），超出关闭语义能力 |
| 可打开文件大小上限 | 20 MB（实测配置），超出拒绝打开 |
| 桩生成大小阈值 | 由语言桩定义独立判定，比可打开上限更严 |
| 单次词法启动 | 超过 500 ms 必须在调试日志记录（实测埋点） |
| 单文件解析耗时 / 惰性子树展开 | 按（语言, 规模）聚合可观测；无固定上限，但必须可取消 |
| 引用缓存 | 按元素驻留，必须可淘汰，不得无限增长 |
| 注入深度 / 注入文本总量 | 必须有限（深度量级 10 层，阈值 `[推断]`） |
| 解析并发 / 桩常驻 | 允许多文件并行解析，同一文件的树构建必须串行；桩必须可整体卸载，树优先于桩驻留 |

解析是可取消计算，取消必须立即生效（每次循环检查），不得"跑完再丢弃"；解析**必须不**分配与文件大小成正比的额外缓冲（不得先复制全文再解析，应直接遍历缓冲区）；桩按访问热度淘汰而非全量常驻，索引查询结果不得跨查询边界强引用桩。

## 9. 可观测性

| 事件 | 必要字段 |
|---|---|
| 语言注册/注销；文件语言判定 | 语言标识、基语言、来源模块；判定路径（显式/类型/替换器）、最终语言 |
| 解析开始/结束；不可解析区产生 | 文件、语言、字节数、是否增量、耗时、是否取消；区间与错误文本 |
| 桩读取/生成/重建；桩与树不一致 | 桩版本、格式版本、原因（过期/不匹配/缺失/损坏）；桩树打印与缓存元素数 |
| 引用解析 | 元素类型、语言、作用域层、命中/未解析/未知、耗时 |
| 注入建立/失效；版本冻结等待；元素替换 | 宿主文件、注入语言、区间数、深度；冻结与实际版本、等待时长；旧/新长度、是否经转义 |

**可聚合指标**：每语言平均解析耗时、未解析引用比例、不可解析字符比例、桩命中率、注入文件数分布、引用提供者耗时前 N。

**诊断入口**：结构树查看器（导出任意文件的结构树：节点类型、范围、元素类型、增量标记，并标注该文件是否使用桩）；桩树打印（与结构树逐行对照）；元素失效追踪（报告"谁在失效后访问了元素"的调用链）；引用提供者耗时表。

**最小可复现状态**：文件内容 + 语言判定结果 + 结构版本 + 桩版本 + 解析范围定义。缺一不可——只有文件内容无法复现"为什么这个引用未解析"。

## 10. 扩展点

| 接缝 | 契约 | 失败隔离 |
|---|---|---|
| 语言接入 | 词法、语法、文件节点、三类记号集合、元素与文件构造、空白要求 | 该语言不可解析，其余正常；其文件退化为纯文本视图 |
| 方言与元语言 | 声明基语言、声明元语言种类、按文件替换语言 | 替换器异常 → 忽略该替换器，保留原语言 |
| 文件视图 | 多语言视图工厂、模板语言修补器、外层语言区间修补器 | 视图工厂异常 → 回落单根视图 |
| 元素增补 | 在既有元素上追加成员/引用/类型（如由注解或外部元数据生成） | 增补异常 → 该元素退回未增补版本 |
| 引用贡献 | 为（元素类型模式, 语言）注册提供者；隐式引用、锚点引用、符号引用 | 单个提供者异常 → 跳过 |
| 桩 | 语言桩定义（版本/构建器/是否建桩）、桩索引、桩元素类型持有者、预置桩 | 桩定义异常 → 不生成桩，索引退化（D1） |
| 注入 | 单宿主注入器、多宿主注入器、注入配置、注入执行器、拼接感知注入器、抑制器 | 单个注入器异常 → 跳过；超限 → 丢弃内层 |
| 值操纵 | 元素操纵器（值区间与替换）、令牌分隔符生成器、引号处理器 | 操纵器缺失 → 按值替换不可用，原地替换仍可用 |
| 符号与类型 | 声明提供者、类型提供者、类型层级提供者、统一语法树语言插件、统一符号查询配置 | 提供者异常 → 该元素无符号/无类型，不影响解析 |
| 树变更观察 | 变更前置处理器（可否决）、变更后监听器 | 监听器异常 → 记录并继续；前置处理器异常 → 变更按原样应用 |

强制约束：扩展**必须不**在解析阶段被调用（解析是纯函数）；扩展**必须**声明哑模式安全性，不安全者在索引未就绪时不得调用；注册必须可静态校验（语言标识存在、类型匹配、桩外部标识唯一且早于索引初始化）；扩展失败的最差结果是"该扩展提供的引用/符号缺失"，不得使整棵树不可用。

## 12. 未决问题

- **增量词法的实际覆盖面**：遍历器支持 `(偏移, 状态)` 恢复，且存在"仅空白变化"的短路接缝；但"编辑点之前不重扫、之后仅重扫至同步点"的完整增量词法是否有统一实现，证据不足，`[推断]` 为"由各语言自行决定，平台只提供恢复点"。
- **版本化语法树的启用条件**：存在"持久化结构"开关与版本化字段，但开关默认值、以及第三方扩展在版本化环境下的可见语义（能否持有跨版本元素）未明确，`[推断]` 为"仅物理文件启用，扩展须按单版本视图使用"。
- **桩序列化的跨大版本兼容**：证据只显示"外部标识 + 版本整数 + 未知类型跳过"，是否支持同版本内兼容旧字段布局，`[推断]` 为不支持。
- **两条跨语言统一视图的分工**：二者并存且部分框架插件同时使用，`[推断]` 为"表达式级 vs 名字级"；本规格不作演进判断。
- **注入深度与文本总量的精确上限**：证据只有"上限存在"与"超限丢内层"，数值未暴露，`[推断]` 为深度 10 层量级。
- **模板语言与注入的优先序**：同一区间既是模板语言外层区间、又是注入宿主候选时，两者有独立接缝但未定义优先序，`[推断]` 为"模板语言先建树，注入在其上再做区间映射"。
- **不可解析区是否参与索引**：桩生成通常跳过不可解析区，但其内部是否仍可能产出声明（如注释标记）证据不足。
- **多项目共享同一文件的桩仲裁**：存在"多项目持有同一文件"的检测与专用异常分类，共享索引下的最终仲裁 `[推断]` 为"以磁盘桩为准，冲突即重建"。
